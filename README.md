# Excel Sales Analytics Dashboard

An interactive and dynamic sales analytics dashboard built in Microsoft Excel to analyze sales performance across products, salespersons, and countries.

## Features

- Interactive PivotTables, PivotCharts and slicers
- Top 10 product analysis by sales and boxes shipped
- Product, salesperson and country-level analysis
- Multi-page navigation
- Dynamic and refreshable dashboard

## Tools Used

Microsoft Excel | PivotTables | PivotCharts | Slicers | Excel Tables | Formulas | Data Validation
